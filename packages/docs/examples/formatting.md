# Formatting

Select cells and make them bold, italic or underlined (the buttons, or Ctrl+B, Ctrl+I, Ctrl+U), give them a text or
fill color, or clear their formatting. Right-click for the **Format** menu with strikethrough and color palettes. Undo
(Ctrl+Z) takes any of it back, and a downloaded Excel file keeps it.
