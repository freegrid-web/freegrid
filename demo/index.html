FreeGrid

A free, MIT-licensed, spreadsheet-like data grid for the web. A continuation of Handsontable 6.2.2.

GitHub ·

Spreadsheet basics

Edit cells (double-click, Enter or just type), drag the fill handle at the bottom-right of the selection, copy and paste to and from Excel, right-click for the context menu, sort by clicking a header, resize or move rows and columns. Undo with Ctrl+Z.


    


    

      
Cell types and validation

      
Numeric with formatting, dates with a picker, checkboxes, dropdowns, autocomplete and passwords. Invalid values are
        highlighted (try typing text into Price or a date in the wrong format).

      

    


    

      
Merged cells, comments and borders

      
Hover the cells with a red corner to read comments. Use the context menu to merge, add comments or borders.

      

    


    

      
10,000 rows, frozen rows and columns

      
Only the visible cells are rendered, so scrolling stays fast. The first column and the header row are frozen.
