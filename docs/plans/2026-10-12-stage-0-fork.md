# FreeGrid Stage 0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn Handsontable 6.2.2 (last MIT release) into the FreeGrid repository: history preserved, rebranded, built with Vite on Node 24, all baseline tests passing under Vitest, Jasmine 5 and Playwright, with CI on GitHub.

**Architecture:** The upstream history up to commit `c2ba2dc` becomes `main`. Sources move to the pnpm workspace package `packages/freegrid`. A Node build script (`build/build.js`) drives Vite's JS API to produce ESM, UMD, CSS and locale outputs. Unit specs run in Vitest through a Jasmine-compatibility shim. Browser specs run unchanged in Jasmine 5 inside Playwright, against the UMD build plus `compat.js`. The upstream test results, recorded in a Node 10 container, are the acceptance baseline.

**Tech Stack:** Node 24 LTS, pnpm 10, Vite 7, Vitest 4 + jsdom, Jasmine 5, Playwright, TypeScript 5, ESLint 9, GitHub Actions, Docker (baseline only).

**Spec:** `docs/specs/2026-10-12-stage-0-fork-design.md`

## Global Constraints

- Upstream base commit: `c2ba2dc02e3eb883a58f976ef5944fa629dc981d` (tag `6.2.2`). No upstream commit after it may enter the repo.
- License: MIT. Keep both original copyright lines and add `Copyright (c) 2026 FreeGrid contributors`.
- Clean-room: nothing from Handsontable ≥ 7.0 or HyperFormula.
- Runtime behavior identical to 6.2.2. No logic changes beyond those the spec lists: polyfill removal, build constants, removing the dead license check, and the moment bump.
- Browser target: `es2020`.
- Node 24 LTS. pnpm, pinned via `packageManager`.
- `moment` → `^2.30.1`. `numbro` stays at `2.1.1` and `pikaday` at `1.5.1` (the upstream lockfile versions, latest patch of each).
- CSS class names (`.handsontable`, `.ht*`) unchanged. The jQuery plugin name `$.fn.handsontable` is unchanged.
- No mass reformatting. File moves and content edits go in separate commits.
- Never delete or weaken a test. An environment-caused failure becomes `xit` with `// FG-SKIP: <reason> — <issue URL>`.
- Conventional Commits. **No AI co-author or "generated by" trailers in any commit or PR.**
- Pushing to GitHub and changing repo settings are outward actions. Confirm with the user before Task 15, Step 5.

## Review Focus

1. **Plugin self-registration under Vite tree-shaking.** Plugins register via import side effects in `src/plugins/index.js`. If Rollup drops a "pure" module, a plugin silently disappears. Pinned by the dist test in Task 8, which asserts that every plugin name from 6.2.2 exists on `FreeGrid.plugins`.
2. **Jasmine 5 randomizes spec order by default; 2.5 did not.** Order-dependent specs would fail intermittently. Pinned in Task 9, where the runner forces `random: false` and the self-test asserts it.
3. **Locale files must register on the global `FreeGrid`.** If they don't, `language: 'de-DE'` silently falls back to English. Pinned by the dist test in Task 8, which loads `languages/de-DE.js` after `freegrid.js` and asserts the dictionary is registered.
4. **The non-full UMD build must not bundle moment, numbro or Pikaday, and the full build must expose `window.moment` and `window.numbro`.** Users who load moment separately would otherwise get two copies, and users relying on the globals would break. Pinned by the dist test in Task 8.
5. **`compat.js` loaded without `freegrid.js` first.** It must fail loudly instead of defining `Handsontable = undefined`. Pinned by the dist test in Task 8.

- [ ] **Step 3: Write the JSON-recording browser runner**

`tools/baseline/run-puppeteer-json.js`. It mirrors upstream `test/scripts/run-puppeteer.js` (same server, viewport and launch args) but records results:

```js
/* Usage: node run-puppeteer-json.js <html path relative to /hot> <out.json> */
const puppeteer = require('puppeteer');
const http = require('http');
const ecstatic = require('ecstatic');
const fs = require('fs');

const [, , htmlPath, outFile] = process.argv;
const PORT = 7992;
const results = [];

(async() => {
  const browser = await puppeteer.launch({
    timeout: 10000,
    headless: false,
    args: ['--no-sandbox', '--disable-setuid-sandbox', '--headless', '--disable-gpu', '--mute-audio'],
  });
  const page = await browser.newPage();
  page.setCacheEnabled(false);
  page.setViewport({ width: 1200, height: 1000 });

  const server = http.createServer(ecstatic({ root: '/hot', showDir: true, autoIndex: true }));
  server.listen(PORT);

  const finish = async(code) => {
    fs.writeFileSync(outFile, JSON.stringify(results, null, 2));
    await browser.close();
    server.close();
    process.exit(code);
  };

  await page.exposeFunction('jasmineStarted', () => {});
  await page.exposeFunction('jasmineSpecStarted', () => {});
  await page.exposeFunction('jasmineSuiteStarted', () => {});
  await page.exposeFunction('jasmineSuiteDone', () => {});
  await page.exposeFunction('jasmineSpecDone', (r) => {
    results.push({ fullName: r.fullName, status: r.status });
    process.stdout.write(r.status === 'failed' ? 'F' : '.');
  });
  await page.exposeFunction('jasmineDone', () => finish(0));
  page.on('pageerror', (msg) => { console.log('\npageerror:', msg); finish(1); });

  await page.goto(`http://localhost:${PORT}/${htmlPath}`);
})();
```

- [ ] **Step 5: Write the normalizer**

`tools/baseline/normalize.mjs`:

```js
// Usage: node tools/baseline/normalize.mjs <dir with raw json> <out file> <source label>
import { readFileSync, writeFileSync, existsSync } from 'node:fs';
import { join } from 'node:path';

const [dir, outFile, source] = process.argv.slice(2);

export function toMap(entries) {
  const map = {};
  const seen = {};
  for (const { fullName, status } of entries) {
    seen[fullName] = (seen[fullName] || 0) + 1;
    const key = seen[fullName] === 1 ? fullName : `${fullName} #${seen[fullName]}`;
    map[key] = status === 'excluded' || status === 'skipped' || status === 'todo' ? 'pending' : status;
  }
  return map;
}

function readJasmine(name) {
  const file = join(dir, `${name}.json`);
  return existsSync(file) ? toMap(JSON.parse(readFileSync(file, 'utf8'))) : null;
}

function readJestLike(name) {
  const file = join(dir, `${name}.json`);
  if (!existsSync(file)) return null;
  const json = JSON.parse(readFileSync(file, 'utf8'));
  return toMap(json.testResults.flatMap(f => f.assertionResults.map(a => ({ fullName: a.fullName, status: a.status }))));
}

const out = {
  source,
  generatedAt: new Date().toISOString(),
  suites: {
    unit: readJestLike('unit'),
    e2e: readJasmine('e2e'),
    walkontable: readJasmine('walkontable'),
    production: readJasmine('production'),
    types: existsSync(join(dir, 'types.json')) ? JSON.parse(readFileSync(join(dir, 'types.json'), 'utf8')) : null,
  },
};
writeFileSync(outFile, `${JSON.stringify(out, null, 2)}\n`);
for (const [k, v] of Object.entries(out.suites)) {
  if (v && typeof v === 'object') {
    const c = Object.values(v).reduce((a, s) => ({ ...a, [s]: (a[s] || 0) + 1 }), {});
    console.log(k, c);
  } else console.log(k, v);
}
```

- [ ] **Step 1: Write the shim's own failing test**

`packages/freegrid/test/setup/jasmine-shim.unit.js`:

```js
describe('jasmine shim', () => {
  it('createSpy records calls and supports .and.returnValue', () => {
    const spy = jasmine.createSpy('s').and.returnValue(42);

    expect(spy(1, 2)).toBe(42);
    expect(spy.calls.count()).toBe(1);
    expect(spy.calls.argsFor(0)).toEqual([1, 2]);
    expect(spy.calls.mostRecent().args).toEqual([1, 2]);
    expect(spy).toHaveBeenCalledWith(1, 2);
    spy.calls.reset();
    expect(spy.calls.count()).toBe(0);
  });

  it('spyOn stubs by default and callThrough restores original behaviour', () => {
    const obj = { f: x => x * 2 };

    spyOn(obj, 'f');
    expect(obj.f(2)).toBeUndefined();
    obj.f.and.callThrough();
    expect(obj.f(2)).toBe(4);
    obj.f.and.callFake(() => 'fake');
    expect(obj.f(2)).toBe('fake');
    expect(obj.f.calls.count()).toBe(3);
  });
```

```js
/* Jasmine-compatible API on top of Vitest, so upstream unit specs run unchanged. */
import { vi, expect } from 'vitest';

function decorate(spy, original) {
  spy.and = {
    returnValue(value) { spy.mockImplementation(() => value); return spy; },
    callFake(fn) { spy.mockImplementation(fn); return spy; },
    callThrough() { spy.mockImplementation(original || (() => undefined)); return spy; },
    stub() { spy.mockImplementation(() => undefined); return spy; },
    throwError(err) { spy.mockImplementation(() => { throw typeof err === 'string' ? new Error(err) : err; }); return spy; },
  };
  spy.calls = {
    count: () => spy.mock.calls.length,
    any: () => spy.mock.calls.length > 0,
    argsFor: i => spy.mock.calls[i] || [],
    allArgs: () => spy.mock.calls.slice(),
    all: () => spy.mock.calls.map((args, i) => ({ args, object: spy.mock.contexts[i], returnValue: spy.mock.results[i]?.value })),
    mostRecent: () => {
      const i = spy.mock.calls.length - 1;
      return i < 0 ? undefined : { args: spy.mock.calls[i], object: spy.mock.contexts[i], returnValue: spy.mock.results[i]?.value };
    },
    first: () => (spy.mock.calls.length ? { args: spy.mock.calls[0], object: spy.mock.contexts[0], returnValue: spy.mock.results[0]?.value } : undefined),
    reset: () => spy.mockClear(),
  };
  return spy;
}

function asymmetric(name, fn) {
  return fn;
}

const jasmineShim = {
  DEFAULT_TIMEOUT_INTERVAL: 15000,
  createSpy(name, impl) {
    return decorate(vi.fn(impl || (() => undefined)).mockName(name || 'spy'), impl);
  },
  createSpyObj(baseName, methodNames) {
    const names = Array.isArray(methodNames) ? methodNames : Object.keys(methodNames);
    const obj = {};
    names.forEach((m) => {
      obj[m] = jasmineShim.createSpy(`${baseName}.${m}`);
      if (!Array.isArray(methodNames)) obj[m].and.returnValue(methodNames[m]);
    });
    return obj;
  },
  any: asymmetric('any', ctor => expect.any(ctor)),
  anything: asymmetric('anything', () => expect.anything()),
  arrayContaining: asymmetric('arrayContaining', arr => expect.arrayContaining(arr)),
  objectContaining: asymmetric('objectContaining', obj => expect.objectContaining(obj)),
  stringMatching: asymmetric('stringMatching', s => expect.stringMatching(s)),
  addMatchers(matchers) {
    const extensions = {};
    Object.keys(matchers).forEach((name) => {
      extensions[name] = function(received, ...args) {
        const result = matchers[name]({ equals: this.equals }, []).compare(received, ...args);
        const message = result.message;
        return {
          pass: !!result.pass,
          message: () => (typeof message === 'function' ? message() : message || `expected ${this.utils.printReceived(received)} ${name}`),
        };
      };
    });
    expect.extend(extensions);
  },
  getEnv: () => ({ addReporter() {}, configure() {} }),

  const spy = vi.spyOn(obj, method).mockImplementation(() => undefined);

/* Jasmine-style `done` callbacks: a test/hook function declaring one parameter receives `done`. */
function withDone(fn) {
  if (typeof fn !== 'function' || fn.length === 0) return fn;
  return function() {
    return new Promise((resolve, reject) => {
      const done = err => (err ? reject(err instanceof Error ? err : new Error(String(err))) : resolve());
      done.fail = err => reject(err instanceof Error ? err : new Error(String(err || 'done.fail() called')));
      try {
        fn.call(this, done);
      } catch (e) {
        reject(e);
      }
    });
  };
}

  if (!original) return;
  const wrapped = (...args) => original(...args.map(a => withDone(a)));
  Object.assign(wrapped, original); // keep it.skip / it.only / it.each
  globalThis[name] = wrapped;
});
```

```js
import { createServer } from 'node:http';
import { readFile } from 'node:fs/promises';
import { extname, join, normalize } from 'node:path';

const TYPES = { '.html': 'text/html', '.js': 'text/javascript', '.css': 'text/css', '.map': 'application/json', '.json': 'application/json', '.png': 'image/png', '.gif': 'image/gif' };

/** Serves files under `root`; `pages` maps URL paths to in-memory HTML. Resolves to { url, close }. */
export function startServer(root, pages) {
  const server = createServer(async(req, res) => {
    const path = decodeURIComponent(new URL(req.url, 'http://x').pathname);
    if (pages[path]) {
      res.writeHead(200, { 'content-type': 'text/html' }).end(pages[path]);
      return;
    }
    const file = normalize(join(root, path));
    if (!file.startsWith(root)) { res.writeHead(403).end(); return; }
    try {
      const body = await readFile(file);
      res.writeHead(200, { 'content-type': TYPES[extname(file)] || 'application/octet-stream' }).end(body);
    } catch {
      res.writeHead(404).end();
    }
  });
  return new Promise((resolve) => {
    server.listen(0, '127.0.0.1', () => resolve({
      url: `http://127.0.0.1:${server.address().port}`,
      close: () => new Promise(done => server.close(done)),
    }));
  });
}
```

`tools/compare-baseline.mjs`:

```js
// Usage: node tools/compare-baseline.mjs <unit|e2e|walkontable|production> <results.json>
import { readFileSync } from 'node:fs';
import { execSync } from 'node:child_process';
import { toMap } from './baseline/normalize.mjs';

const [suite, file] = process.argv.slice(2);
const baseline = JSON.parse(readFileSync(new URL('../docs/baseline/6.2.2-results.json', import.meta.url), 'utf8')).suites[suite];
const raw = JSON.parse(readFileSync(file, 'utf8'));
const entries = Array.isArray(raw)
  ? raw
  : raw.testResults.flatMap(f => f.assertionResults.map(a => ({ fullName: a.fullName, status: a.status })));
const now = toMap(entries);

if (!baseline) {
  console.log(`No baseline for "${suite}" — every non-passing test needs an issue.`);
}

const skipCount = (execSync('git grep -h "FG-SKIP" -- ":/packages/freegrid" || true', { encoding: 'utf8' }).match(/FG-SKIP/g) || []).length;
const regressions = [];
const skippedNow = [];
const newlyPassing = [];

for (const [name, status] of Object.entries(baseline || now)) {
  const current = now[name];
  if ((baseline ? status === 'passed' : true) && current !== 'passed') {
    const line = `${name}  [baseline: ${baseline ? status : 'n/a'}, now: ${current ?? 'missing'}]`;
    (current === 'pending' ? skippedNow : regressions).push(line);
  }
}
// A baseline-passing test may only become pending through an FG-SKIP marker.
if (skippedNow.length > skipCount) regressions.push(...skippedNow.map(l => `${l}  (pending without enough FG-SKIP markers)`));
if (baseline) {
  for (const [name, status] of Object.entries(now)) if (status === 'passed' && baseline[name] && baseline[name] !== 'passed') newlyPassing.push(name);
}

console.log(`${suite}: ${Object.keys(now).length} now, ${baseline ? Object.keys(baseline).length : 0} in baseline`);
console.log(`FG-SKIP markers in repo: ${skipCount}; baseline-passing tests now pending: ${skippedNow.length}`);
if (newlyPassing.length) console.log(`Newly passing (${newlyPassing.length}):\n  ${newlyPassing.join('\n  ')}`);
if (regressions.length) {
  console.log(`REGRESSIONS (${regressions.length}):\n  ${regressions.join('\n  ')}`);
  process.exit(1);
}
console.log('No regressions.');
```

The comparator matches tests by `fullName`. Tests that are missing from the new run count as regressions, which catches specs the harness failed to load.

- [ ] **Step 3: Triage loop (repeat until no regressions in every suite)**

For each suite: `unit` (`packages/freegrid/test-results/unit.json`), `e2e` (`e2e-dev-chromium.json`), `production` (`e2e-min-chromium.json`), `walkontable` (`walkontable-dev-chromium.json`):

1. Run the comparator.
2. Pick one regression. Rerun just that spec: `node test/runner/run.js --suite e2e --grep "<fullName>"`.
3. Classify the cause and fix accordingly:
   - **Harness or toolchain cause** (load order, missing global, Vite output difference, Jasmine 5 API such as `done.fail`, `expectAsync`, custom matcher signature, or the clock): fix the harness. A mechanical spec API update is allowed only when the semantics stay the same.
   - **Real FreeGrid regression** (behavior differs because of our build or source edits): fix the source or build.
   - **Environment cause** (a newer Chromium changes layout or pixel metrics, or an event-model difference): mark `xit` with `// FG-SKIP: <specific reason> — <issue URL or TBD-ISSUE>`.
4. Rerun the comparator and commit each fix category separately (`fix:`, `test:`, `build:`).

Hard rule: an `FG-SKIP` without a specific reason is not allowed. "flaky" alone is not a reason. Rerun the spec 3 times; if it passes at least once, describe the timing dependency.

```yaml
name: CI
on:
  push:

jobs:
  checks:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v5
      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v5
        with: { node-version-file: .nvmrc, cache: pnpm }
      - run: pnpm install --frozen-lockfile
      - run: pnpm lint
      - run: pnpm --filter freegrid test:unit
      - run: pnpm --filter freegrid test:types
      - run: pnpm --filter freegrid build
      - run: pnpm --filter freegrid test:dist

  browser:
    needs: checks
    runs-on: ubuntu-latest
    strategy:
      fail-fast: false
      matrix:
        include:
          - { name: e2e-chromium-dev, script: 'test:e2e', required: true }
          - { name: e2e-chromium-min, script: 'test:e2e:min', required: true }
          - { name: walkontable-chromium, script: 'test:walkontable', required: true }
          - { name: e2e-firefox, script: 'test:e2e:firefox', required: false }
          - { name: e2e-webkit, script: 'test:e2e:webkit', required: false }
    name: ${{ matrix.name }}
    continue-on-error: ${{ !matrix.required }}
    steps:
      - uses: actions/checkout@v5
      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v5
        with: { node-version-file: .nvmrc, cache: pnpm }

      - run: pnpm --filter freegrid exec playwright install --with-deps
      - run: pnpm --filter freegrid build
      - run: pnpm --filter freegrid ${{ matrix.script }}
      - uses: actions/upload-artifact@v4
        if: always()
        with: { name: results-${{ matrix.name }}, path: packages/freegrid/test-results }
```
