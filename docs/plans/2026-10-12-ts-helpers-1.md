**Goal:** Convert 16 files of `packages/freegrid/src/helpers/` to strict TypeScript in modern syntax, with the same
behavior: `array`, `browser`, `classNames`, `console`, `data`, `date`, `feature`, `function`, `immediate`, `mixed`,

**Architecture:** The user asked for a visible conversion to modern TypeScript now, with the cleanup done inside the

Part 2 (`dom/element` split into smaller modules, `dom/event`, `wrappers/jquery`) is a separate PR. Importers stay
untouched: imports have no extension, and every exported name and its runtime behavior stay the same, including
`FreeGrid.helper.*` (copied from these modules in `src/index.js`).

**Tech Stack:** TypeScript 5.9 (strict, `verbatimModuleSyntax`), Vite/esbuild, Vitest, Jasmine E2E via Playwright.

**Spec:** `docs/specs/2026-10-12-typescript-and-clean-code-design.md` (§2 principles, §3 phase 3 "Foundations")

## Global Constraints

- **Style (user's rule):** exported and internal functions are `export const name = (…): T => { … };`. Classes keep
  regular methods. `const`/`let` only, `?.`/`??` where they read better and keep behavior, no `var`, no `==`.
- **Exception:** a function that uses its own `this` or `arguments` stays a `function` expression with a typed
  `this` parameter: `throttle`, `debounce`'s/`pipe`'s/`partial`'s/`curry`'s returned wrappers, the accessors that
  `defineGetter`/`createObjectPropListener`-style helpers in `object` build, the `cellMethodLookupFactory` closure in
  `data`.
- **Order:** `const` arrows are not hoisted. A module that calls one of its functions at top level (e.g.
  `setBrowserMeta()` in `browser`) must define it first.
- **Same behavior:** keep loose JS-caller semantics (array-likes, holes, coercions). Types describe the intended use;
  they must not change what runs. No `any` unless commented (`unknown` + narrowing, generics instead).
- Names and the set of exports stay the same (public `FreeGrid.helper.*`). Do not delete helpers in this PR.
- Separate `git mv` commit, then typing commits; merge with **Rebase and merge**. No `Co-Authored-By` lines.
- Unit, types, dist and E2E green in Chromium (baseline), Firefox and WebKit (known failures). Browser tests locally
  through `tools/in-playwright-docker.sh`.

## Review Focus

1. **`this`/`arguments` lost by an arrow** (throttle/debounce/pipe/partial/curry wrappers, object accessors):
   callers that pass a context would get `undefined`. Existing `Function.spec.js` covers throttle/debounce timing;
   Task 1 adds `this`-forwarding pins.
2. **TDZ at module load:** a top-level call to a `const` declared later throws `ReferenceError` on import. Covered by
   unit (imports every module) and dist tests.
3. **Array-likes and holes** in `array`/`object` helpers (`Array.from` copies, `objectEach` over own props):
   behavior must not change; existing `Array.spec.js`/`Object.spec.js`.
4. **`FreeGrid.helper` export set** unchanged: Task 1 adds a dist test listing every exported helper name.
5. **`immediate`** batching semantics (`immediate.unit.js` exists).
